# Mitmachen

NexRedirect ist ein kleines Tool. Änderungen gerne als Pull Request gegen `prod`.

## Vor dem Pull Request

- Kurz beschreiben, welches Verhalten sich ändert.
- Wenn es eine Oberfläche betrifft: den Weg einmal selbst durchklicken.
- Keine `.env`, Datenbanken oder echten Kundendaten ins Repo legen.

Lokal starten:

```bash
npm install
npm run dev
```

## Sicherheitslücken

Nicht als Issue. Mail an security@corexmanagement.de, siehe [SECURITY.md](SECURITY.md).
